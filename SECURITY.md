# Security Policy

## Supported Versions

The following versions of **CNAB Sync** are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of CNAB Sync and the privacy of financial file processing seriously.

If you believe you have discovered a security vulnerability or sensitive data handling issue, please **do not open a public GitHub issue**.

### How to Report

Please report vulnerabilities privately via **[GitHub Security Advisories](https://github.com/your-username/CNAB_Sync/security/advisories/new)**:

1. Navigate to the **Security** tab of this repository on GitHub.
2. Select **Advisories** and click **Report a vulnerability**.
3. Provide a clear description of the vulnerability, including:
   - Type of issue (e.g., buffer handling, path traversal, injection, sensitive data leakage).
   - Detailed step-by-step instructions to reproduce the issue.
   - Any sample files (ensure any CPF/CNPJ or real banking details are anonymized or replaced with dummy test data).
   - Potential impact of the issue.

### Our Commitment

- We will acknowledge receipt of your vulnerability report within 48 to 72 business hours.
- We will coordinate with you during the investigation and validation process.
- Once a fix is verified, a coordinated release and advisory will be published.
